# English Vocabulary Trainer — скилл для Claude

Скилл для Claude, который превращает ваш личный словарь в Notion в тренажёр английского. Claude
берёт слова из вашей базы, даёт упражнения, проверяет ответы (и лексику, и грамматику), разбирает
ошибки, обновляет статусы слов и ведёт журнал ошибок с темами для повторения.

Сделан для русскоговорящих, которые учат или восстанавливают английский, особенно с упором на рабочие встречи и деловую переписку. Приоритет и уровень настраиваются.

## Что умеет

| Набор | Время | Что внутри |
|---|---|---|
| 1. Быстрый разогрев | 15–20 мин | EN→RU, RU→EN, fill the gaps, перевод предложений, объяснение значения |
| 2. Полный урок (по умолчанию) | 30–40 мин | то же + составление собственных предложений и устное объяснение |
| 3. Деловая практика | 15–20 мин | слова с типом «деловое»: рабочие фразы, письма, реплики на созвонах |
| 4. Работа над ошибками | 15–20 мин | задания на основе вашего журнала ошибок и слабых мест |

Дополнительно:
- **Добавление слов** текстом или диктовкой: достаточно написать «добавь слова stakeholder, follow up on
  something» — перевод и пример Claude подберёт сам (и пометит, что они его).
- **Журнал ошибок**: после каждого урока ошибки попадают в журнал с категорией и правилом; слабые
  места определяются автоматически.
- **Темы для изучения** после каждого урока: до 5 тем с правилом и примерами.
- **Статусы слов**: Новое → Учу → Закрепляю → Знаю, счётчик тренировок и дата последней практики.
- Ответы проверяются **после** последнего задания набора, чтобы не подсказывать по ходу.

## Требования

- Claude с возможностью добавлять собственные скиллы (доступность зависит от вашего тарифа).
- Подключённый коннектор **Notion** к Claude.
- Три объекта в Notion (скилл умеет создать их при первом запуске — см. ниже):
  «Английский словарь», «Журнал ошибок», «Заметки тренера — english-vocab-trainer».
  Схемы полей описаны в [docs/notion-setup.md](docs/notion-setup.md). Можно обойтись одной базой
  «Английский словарь»: тогда наборы 1–3 и добавление слов работают, а набор 4 недоступен.

## Установка

**Claude (веб и приложения).** Скачайте этот репозиторий, заархивируйте папку
`english-vocab-trainer` (внутри архива `SKILL.md` должен лежать в папке `english-vocab-trainer/`)
и добавьте архив в разделе настроек, где находятся скиллы (Skills). Названия пунктов меню могут
меняться — ориентируйтесь на документацию Claude по загрузке собственных скиллов.

**Claude Code.** Скопируйте папку `english-vocab-trainer` в `~/.claude/skills/` (для всех проектов)
или в `.claude/skills/` внутри проекта.

## Первый запуск

1. Подключите Notion в Claude и разрешите доступ к страницам, где будут лежать (или уже лежат) ваши
   базы.
2. Напишите, например: «давай потренируем вокабуляр».
3. Если баз ещё нет, Claude предложит создать их по схеме — вы выберете страницу Notion для них и
   подтвердите. Если база «Английский словарь» уже есть, Claude найдёт её по названию и сообщит,
   каких полей не хватает.
4. Claude один раз спросит ваш уровень и приоритетный контекст (например, «рабочие встречи и деловая
   переписка») и сохранит ответ в заметках тренера.

Идентификаторы баз в скилле не хранятся — он находит их по названию, поэтому один и тот же скилл
работает у любого пользователя со своими данными.

## Как пользоваться

Примеры фраз:
- «потренируй меня» — полный урок (набор 2)
- «быстрый вокабуляр» — набор 1
- «деловой вокабуляр» — набор 3
- «работа над ошибками» — набор 4
- «добавь слова: stakeholder, agenda» — добавить слова
- «разбери мой прогресс» / «что мне подтянуть» — анализ журнала ошибок

Отвечайте на задания по одному сообщению на задание. Разбор придёт после последнего.

## Приватность

Скилл не содержит ничьих личных данных. Слова, ошибки и заметки хранятся только в вашем Notion;
Claude читает и пишет их через ваш коннектор.

## Ограничения

- Произношение не оценивается: по текстовой расшифровке голоса оценить фонетику нельзя. Для этого
  используйте голосовой режим приложения или отдельный сервис.
- Скилл зависит от Notion-коннектора и структуры баз из [docs/notion-setup.md](docs/notion-setup.md).
- Инструкции и разборы по умолчанию на русском.
