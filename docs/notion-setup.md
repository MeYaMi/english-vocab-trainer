# Настройка Notion для english-vocab-trainer

Скилл работает с тремя объектами в вашем Notion. При первом запуске Claude может создать их сам
(он спросит, на какой странице их разместить). Если хотите создать вручную — используйте схемы
ниже. Названия баз важны: скилл ищет их по названию.

Названия полей и значений нужно сохранить точно, иначе Claude не найдёт нужные поля.

## 1. База «Английский словарь»

| Поле | Тип | Назначение |
|---|---|---|
| `Word` | Заголовок | Английское слово или выражение |
| `Перевод` | Текст | Значение по-русски (+ короткая пометка о нюансах) |
| `Пример` | Текст | Законченные предложения-примеры |
| `Фразы` | Текст | Коллокации и устойчивые сочетания, по одной на строку: `фраза — перевод` |
| `Тип` | Мульти-выбор | `бытовое`, `деловое` (у слова могут быть оба значения) |
| `Статус` | Выбор | `Новое`, `Учу`, `Закрепляю`, `Знаю` |
| `Дата добавления` | Дата | Когда слово добавлено |
| `Последняя тренировка` | Дата | Заполняется скиллом |
| `Раз потренировано` | Число | Заполняется скиллом, начальное значение 0 |

Статус двигается вперёд, когда слово отвечено верно во всех упражнениях сессии:
Новое → Учу → Закрепляю → Знаю.

## 2. База «Журнал ошибок»

| Поле | Тип | Назначение |
|---|---|---|
| `Ошибка` | Заголовок | Короткое название ошибки |
| `Дата` | Дата | Дата урока |
| `ID сессии` | Текст | Например, `ГГГГ-ММ-ДД #1` |
| `Набор` | Выбор | Набор 1 / 2 / 3 / 4 |
| `Упражнение` | Текст | Какое упражнение |
| `Категория` | Выбор | Артикли, Предлоги, Времена, Порядок слов, Согласование, Выбор слова, Коллокации, Калька с русского, Орфография, Другое |
| `Сфера` | Выбор | `встречи`, `переписка`, `общее` |
| `Слово` | Текст | Слово из словаря, к которому относится ошибка |
| `Мой вариант` | Текст | Как ответил пользователь |
| `Исправление` | Текст | Правильный вариант |
| `Правило` | Текст | Короткое объяснение |
| `Статус` | Выбор | `Активная`, `Закрыта` |
| `Верно подряд` | Число | Сколько раз подряд задание по этой ошибке выполнено верно; при 3 запись закрывается |

Типы полей `Набор`, `Упражнение`, `Слово`, `Мой вариант`, `Исправление`, `Правило` — рекомендованные;
скилл ориентируется на названия, а не на строгие типы.

## 3. Страница «Заметки тренера — english-vocab-trainer»

Обычная страница Notion с заголовками блоков:

- **Приоритеты** — уровень, цель, приоритетный контекст (по умолчанию: B1–B2, рабочие встречи и
  деловая переписка)
- **Что считается слабым местом** — правило: категория ошибок, встретившаяся минимум в 2 разных
  упражнениях одной сессии, в минимум 2 сессиях за 14 дней
- **Слабые места сейчас** — обновляется скиллом после каждого урока (содержимое заменяется целиком)
- **Подтверждённые правила разбора** — договорённости о том, как проверять ответы
- **Пожелания по формату** — например, «меньше теории, больше примеров»
- **Журнал наблюдений** — короткие датированные строки; скилл только дописывает

Скилл читает эту страницу в начале каждой сессии. Когда записей в журнале наблюдений становится
больше примерно 30, Claude предложит свернуть их в краткое резюме.

## Минимальный вариант

Если журнал ошибок и заметки не нужны, достаточно только базы «Английский словарь». Тогда наборы
1–3 и добавление слов работают, а набор 4 («Работа над ошибками») недоступен.
